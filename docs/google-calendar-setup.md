# Googleカレンダー同期の初期設定（無料・最初の1回だけ）

アプリが「あなたのGoogleカレンダーを読み取るだけ」の許可をもらうための設定です。Mac のブラウザで行います。
画面の名前は Google 側の変更で少し違うことがあります。迷ったら Claude Code に画面の状態を伝えてください。

## 先に必要なもの

- アプリの公開URL（GitHub Pages のURL。例：`https://ユーザー名.github.io/tegaki-techo/`）
  - Claude Code の「3. 公開」が終わってから、この設定に進みます。

## 手順

1. **Google Cloud コンソールを開く**
   - https://console.cloud.google.com/ に、カレンダーを使っている Google アカウントでログインします。
   - 初めての場合は利用規約に同意します。料金の登録（クレジットカード）は不要です。

2. **プロジェクトを作る**
   - 上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は「手書き手帳」など → 作成。

3. **Google Calendar API を有効にする**
   - 「APIとサービス」→「ライブラリ」→「Google Calendar API」を検索 →「有効にする」。

4. **同意画面（Google Auth Platform）を設定する**
   - 「APIとサービス」→「OAuth 同意画面」（または「Google Auth Platform」）。
   - アプリ名：手書き手帳、サポートメール：自分のアドレス。
   - 対象（ユーザーの種類）：**外部**。
   - 公開ステータスは **テスト** のままにします。
   - 「テストユーザー」に、自分の Google アカウントのメールアドレスを追加します。
   - スコープ（データアクセス）に `.../auth/calendar.readonly` を追加します。

5. **OAuth クライアント ID を作る**
   - 「認証情報」（または「クライアント」）→「認証情報を作成」→「OAuth クライアント ID」。
   - 種類：**ウェブ アプリケーション**。
   - 「承認済みの JavaScript 生成元」：`https://ユーザー名.github.io`
   - 「承認済みのリダイレクト URI」：アプリの公開URL（例：`https://ユーザー名.github.io/tegaki-techo/`。末尾の `/` まで正確に）。
   - 作成すると「クライアント ID」（`xxxx.apps.googleusercontent.com`）が表示されます。

6. **クライアント ID を Claude Code に伝える**
   - 「クライアント ID は ○○ です」と Claude Code に貼り付けてください。
   - クライアント ID は公開されても問題のない値です。クライアントシークレットは使いません。

## 初めて同期するとき

- アプリのメニューから「Googleカレンダーを同期」を押すと、Google のログイン画面に移ります。
- 「このアプリは Google で確認されていません」と表示されます。自分で作ったテスト用アプリのためで、「詳細」→「手書き手帳（安全ではないページ）に移動」で進みます。
- 「Google カレンダーの表示」だけが求められていることを確認して許可します。予定の作成・変更・削除の権限は求めません。

## 知っておくこと

- 許可は約1時間で切れます。切れたときは、アプリを開いたときに自動で取り直します。自動で取り直せないときは、もう一度ログインを求められます。
- 許可を取り消したいときは https://myaccount.google.com/permissions から「手書き手帳」を削除します。
